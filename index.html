Administração

Configuração e segurança do painel

Atenção: esta primeira interface ainda não é um painel privado.Ela mostra metadados públicos do GitHub e não implementa autenticação de administrador. Antes de publicar informações privadas ou comandos de gestão, é necessário configurar autenticação no servidor/Cloudflare Access e armazenar segredos fora do navegador.

Monitoramento GitHub

Consulta pública periódica de commits, issues, releases e workflows. Sem token privilegiado no frontend.

Proteção de acesso

Configurar Cloudflare Access ou autenticação equivalente para restringir rotas administrativas.

Eventos dos aplicativos

Backend com validação, rate limiting, retenção e métricas agregadas para dispositivos e sessões.

Alertas automáticos

GitHub Actions agendado e webhooks para detectar mudanças e falhas com menos atraso.

Histórico de mudanças

Persistência dos eventos em armazenamento confiável; a interface não finge guardar histórico no navegador.

Segredos e permissões

Tokens com privilégio mínimo em secrets do servidor ou GitHub Actions. Nunca embutir chaves no site.

Este painel não altera, publica ou atualiza automaticamente os aplicativos. No primeiro estágio, ele observa e apresenta informações. Deploys e atualizações de produção devem continuar protegidos por aprovação explícita.
