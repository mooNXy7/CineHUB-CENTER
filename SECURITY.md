# Security Policy

## Reportar vulnerabilidades

Não publique tokens, senhas, chaves privadas, dados pessoais ou detalhes exploráveis de uma vulnerabilidade em issues públicas.

Para problemas de segurança, use um canal privado controlado pelo mantenedor do projeto. Até que um canal privado seja configurado, evite anexar dados sensíveis a tickets públicos.

## Regras de segurança do CineHUB CENTER

- Não colocar tokens de GitHub, segredos de Cloudflare ou chaves privadas em arquivos públicos, APKs ou código executado no navegador.
- O dashboard público consulta apenas metadados públicos e não deve ser considerado uma área administrativa autenticada.
- Operações que alterem repositórios, publiquem releases ou iniciem OTA devem exigir autenticação, autorização explícita e registro de auditoria.
- Telemetria deve ser minimizada, pseudonimizada e documentada antes de ser ativada.
- Dependências e workflows devem usar permissões mínimas necessárias.
